# Profile
- Chỉ mở trang profile khi click avatar/username
- Khi click vào bài đăng -> chi tiết bài đăng
- Khi click vào một user (Hiện thông tin user và các bài đăng của họ) không cache (chỉ cache acc hiện tại)
- dùng ảnh ở local load trang chỉnh sửa profile
- Không cache ảnh trang profile khi đăng xuất
- Lỗi đổi avatar:
  - hiện tại: avatar1
  - chọn đổi thành avatar2
  <br>-> bấm ok
  <br>-> ngay lập tức đối avatar (không cần chờ BE response) (avatar ở thanh điều hướng đã đổi thành avatar2)
  <br>-> khi BE response thành công -> avatar ở thanh điều hướng đổi thành avatar mặc định -> avatar2
  <br>(lỗi, khi BE thành công thì không cần cập nhật giao diện, chỉ rollback thông tin cũ khi BE fail)
