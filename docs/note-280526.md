# Trang profile:

- vị trí avatar lệch với ảnh bìa
- font chữ trang "Cài đặt trang cá nhận" bị lớn
- đổi lại change_info_after_signup dùng file thay vì link:
  - đổi ảnh đại diện tốn nhiều thời gian -> dùng lazy load
- auto tìm khi nhấn vào hastag
  trang home:
- avatar mặc định phần bình luận
- chỉnh lại layout (optional)
- không gửi được bình luận (một số bài đc 1 số bài không)
- layout đăng bài: chọn từng video một (trái + phải) -> đổi lại giao diện bỏ "Video (0/2)"
- Không cho đăng 2 video khác thời lượng
- hoàn thiện lưu bản nháp khi đăng bài

# Trang settings:

- Chỉnh lại giao diện cho giống fb
- đổi mật khẩu
- danh sách block, report
- cài đặt thông báo (âm thanh, rung...)

# Trang conversation (chat giữa 2 người)

- giao diện các conversation, xóa conversation
- giao diện chat giữa 2 người (các tin nhắn trong conversation)
  - giao diện đã đọc / chưa đọc
  - xóa tin nhắn
- Lưu ý:

* có cache, khi gửi, update luôn bên mobile thay vì đợi BE response (lazy load)
* Hỗ trợ xem giao diện profile partner

# Trang menu

- Nút thoát ứng dụng
- Lược bớt những phần không dùng như
